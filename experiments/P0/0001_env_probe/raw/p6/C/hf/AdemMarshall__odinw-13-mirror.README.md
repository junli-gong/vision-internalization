# ODinW-13 — pinned mirror

Byte-identical copy of the thirteen ODinW-13 dataset archives from
[`GLIPModel/GLIP`](https://huggingface.co/GLIPModel/GLIP) at revision
`66ee3ae9a3b8cee0cf78f10ef5fc9a3725db02a1`, path `odinw_35/`. Verify with
`SHA256SUMS.txt`.

Rehosted so that the `odinw-inspect` Inspect AI eval depends on a stable,
pinned source. Nothing has been modified, converted or re-annotated.

## Licences

These are thirteen independently licensed datasets — six Public Domain, five
CC BY 4.0, one MIT, one ODbL v1.0 (pothole). Per-dataset terms, attribution
and the original Roboflow README files are in `ATTRIBUTION.md` and
`licenses/`. Downstream use must honour each dataset's own licence; pothole's
ODbL share-alike applies to derived databases.

ODinW-13 was introduced in GLIP (arXiv 2112.03857); the datasets originate
from Roboflow contributors credited in `ATTRIBUTION.md`.
