## 4. 与任务书假设不符的发现

- **用时：** 任务书预计 4–6 GPU 小时，大模型每个 40–70 分钟。实际 4.89 h。
  - internvl3.5-4b-hf 主口径 67.0 min，加附加口径共 92.3 min；

- **思考吞吐对照的样本不同（只陈述）：**
  - RUN-0013 每任务 8 条；本次 `--estimate-think-n 64`，开发子集不足 64 条的任务全取：count 49、rel_depth_blink 12、两个空间问答 50。两次用的样本数与样本组成都不同。
  - 比值 < 1 的有 3 格：
    - qwen3.5-0.8b refexp_box：0.19；
    - gemma-4-e2b-it refexp_poly：0.39；
    - internvl3.5-2b-hf rel_depth_blink：0.49。
  - internvl3.5-2b-hf count 是 1.11。
  - 平均生成 token 与截断率见 §3 的"开思考的实测"表；RUN-0013 的对应数字在 RUN-0013 report 的 §3.2。
- **运行期间有代码提交：** 见 §1。三个小模型加载的是新的 `src/e1/scoring.py`，改动只是导入路径，正则逐字节相同。
- **nvidia-smi 与 torch 两列口径不同。** nvidia-smi 那一列是 5 s 一次的采样，按进程取 used_memory，可能漏掉瞬时峰值。torch 那一列是各批大小、思考、free 实测里 `max_memory_allocated` 的最大值。
