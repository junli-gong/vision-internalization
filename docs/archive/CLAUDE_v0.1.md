# 项目说明（给Claude Code）

**放置方式：** 本文件放在仓库根目录，简报放在 `docs/RESEARCH_BRIEF.md`。下一行会在每次启动时把完整简报自动载入上下文：

@docs/RESEARCH_BRIEF.md

**阅读要求：**
- 开始任何任务前，先读完简报。
- 进入新阶段前，重读简报第2、4、8、10节。

**最重要的规则**（完整版见简报第4节和第10节）：

- **能力必须长在LLM权重里。** 循环中不使用任何学习型CV专家模型，无论作为工具、教师、伪标签来源还是奖励模型都不行。
- **稠密解码器是训练时的仪器。** 它必须：
  - 足够薄，默认不超过50M参数；
  - 跨任务共享；
  - 只读LLM隐藏状态，看不到像素。
- **结论口径。** 所有"LLM能力"的结论，都以文本通道、合并后的单一权重为准。
- **代码与模型无关。** 模型相关的逻辑放在 `src/adapters/` 里，不硬编码层号。
- **决策门。** 每个决策门都要提交门报告，未经项目负责人确认不进入下一阶段。
- **请示流程。** 需要决策时写入 `DECISIONS_NEEDED.md`，然后继续做不受影响的工作。
- **记录。**
  - 主实验前写 `PREREGISTRATION.md`。
  - 每次工作都更新 `RESEARCH_LOG.md`。
- **长任务。** 预计超过12小时的任务，先估算，再请求批准。
- **拿不准就先问。** 不确定是否违反约束时，按违反处理。
