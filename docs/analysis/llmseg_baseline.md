## 4. 读法

- **定位不变**：开源 9B 零样本配上最好的公开几何回路，比我们训练过的 W2-c 低得多（−0.25 到 −0.37）。LLMSeg 的论文没有回答"开源小模型能不能做到"，这正是我们的位置（directive 第二节第 5 条）。
- **修正环在 9B 上有害**：带符号的局部修正从修正前的 0.398 降到 0.275。
  - 与 LLMSeg 论文里开源 26–27B 后端"修正几乎无效"方向一致，在更小的模型上更糟。
  - 与我们 W1 的发现相同，"修改把好的结果改坏"，但 W1 的写法要限定在"我们的回路设计与 9B"（directive 第二节第 5 条）。
  - 这也提示探索 X-2 的修正设置要警惕同样的问题（探索日志 X-2 已记）。
- **未跑 4B**（D135）：9B 的实测用时（14 小时）进一步说明不便宜。
- **论文里的写法**：LLMSeg 作为外部参照列在 test 表里，两组读数都给，附计算量。Gemini 的数字只引用为参考。
