## 2. 每项读数怎么写

- **MMLU-Pro**：−0.2 到 −2.3，三个种子都远小于 W2-c 的 −9.0。**可以明确写这个比较。**
- **IFEval**：0.0 到 −3.5，与 W2-c 的 −4.6 接近。**不宣称更好。**
- **计数**：
  - 写 3 个种子的范围：−8.1 到 −16.1，均值约 −10.9。注明 W2-c、X-3 只有 1 个种子。
  - 与 W2-c（−13.1）在同一范围，分不出高下，**写成工具路线共同的代价**。
  - X-3 的 −17.4：只写"计数代价随种子变化约 8 点，X-2 与 X-3 的差在这个范围之内"。原来那句"多训一个相关任务可能有助于维持语言能力"删去。
  - 计数是 X-2 唯一明显的代价，在局限里照实写。
- **以大题量为准**（D154）：健康检查的标红只作并列说明。
  - 50 条的 IFEval 上，seed 1、2 标红（−12、−6）；seed 0 不标红（−4）。
  - 以大题量为准，三个种子都没有超过 3.5 点的语言代价。

## 3. 种子稳定性（一句）

- 三个种子的分割在开发数据上几乎相同：2,300 句合并 0.730、0.731、0.732，标准差 0.0009；对 W2-c 都是 +0.095 到 +0.097。
- 差异全在语言的副作用上，主要是计数。出处：`docs/analysis/seed_variance.md`。

## 4. 局限一节：计数错误的方向（只记现象，不作解释；D154、D162）

CountBench，真值 5–10 个物体时，错误里"数多"与"数少"各占的比例（出处 `docs/analysis/count_errors_c1_seeds.md`，与同一个基座配对）：

| | 5–7 个：数多 / 数少 | 8–10 个：数多 / 数少 |
|---|---|---|
| 基座 | 0.05 / 0.06 | 0.04 / 0.09 |
| W2-c | **0.26** / 0.06 | **0.29** / 0.05 |
| X-2 seed 0 | 0.04 / **0.21** | 0.04 / **0.24** |
| X-2 seed 1 | 0.03 / **0.26** | 0.07 / **0.37** |
| X-2 seed 2 | 0.06 / **0.20** | **0.18** / 0.09 |
| X-3 | 0.06 / 0.16 | **0.36** / 0.19 |

- 2–4 个物体时，所有系统都与基座接近。
- W2-c 的计数错误以数多为主。
- X-2 在 5–7 个时三个种子都以数少为主。
- 8–10 个时，seed 0、1 以数少为主，**seed 2 以数多为主**。
- 所以"数多变数少"在 5–7 个时三个种子一致；在 8–10 个时不一致。照实写，不作解释。
