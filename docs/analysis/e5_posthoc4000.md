## 2. 按事先写下的读法（§8e，写于任何 4000 步运行之前）

- **R1"优势被训练预算掩盖了"**：要求至少 3 类同时满足"E3b+C3 过门槛"与"仍显著优于 C3+预热"。实际 **0 类**。
  - c 显著但没过门槛；d、e 过门槛但不显著。
  - **不成立。**
- **R2"内化只让模型更早走出空网格"**：要求两个起点各自都在至少 3 类上过门槛，并且 R1 不成立。实际两个起点都只在 d、e **2 类**上过门槛。
  - **不成立。**
- **R3"在这个规模上，三维想象任务学不会"**：要求 a、b 两类、两个起点、3 个种子的空网格比例都 ≥ 0.5。实际都 ≤ 0.01。
  - **不成立。**
- **按规则：不确定。** 照实报告上面的读数。

## 3. 管理员的读法（描述，不改上面的判定）

- **方向上最接近 R2。** 训练加到 4 倍之后：
  - 两个起点都走出了空网格，读数趋同；
  - d、e 上的差距从 +0.21、+0.14 降到 0（不显著），两者都胜过平凡基线；
  - c 上的差距从 +0.40 降到 +0.08。仍显著，但两者都没胜过平凡基线（可见部分及其凸包）。
  - 也就是说，1000 步时 E3b+C3 的大幅领先，主要是 C3+预热那时还没走出空网格。
  - R2 没有成立，只是因为 c 类两者都没过门槛，不是因为差距还在。
- **a、b 这两类真正要求三维想象的任务**：
  - 4000 步时两者都输出了非空的网格，但都没胜过平凡基线；
  - b 上 C3+预热反而略好。
  - 所以"学不会"不是因为输出塌缩，而是学到的东西还不如复制或二维变换。这与 G5 及负责人 D103 的表述一致：在 a、b 上没有任何差别。
- **对论文的意义**：E5 作为诚实的否定结果。
  - 1000 步时的显著优势，在 4 倍训练量下大部分消失；
  - 内化视觉的起点，没有在想象任务上带来持久的领先。
