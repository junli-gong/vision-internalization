## 4. 读法

- **回放几乎是免费的缓解**：分割不变，MMLU-Pro 的损失从 −9.0 收到 −2.0，计数从 −13.1 收到 −9.0。
- **回放没修好的**：
  - IFEval：大题量 −4.6 → −3.5，健康检查仍标红。
  - 多物体（8–10）的计数。
- **IFEval 的一个可能原因**：通用回放剔除了 38% 写满上限的长回答（D137），留下的回答偏短。这是猜测，没有检验。
- **论文的写法**：W2-c 的语言代价照实列出（D125-3），W2-c+回放作为事后的缓解与之并列；回放的"不要求额外监督"一点要讲清楚。
