一、N30：E5主比较开训前的补全

1. E3a的对照：选(a)。 和E3b一样，都对比"基座加预热"，另加诊断起点"基座、不预热"（1K、4K，种子0）。

诊断起点除了量出格式预热本身的作用，还有一个用途：如果预热的作用很大，"E3a对基座加预热"就明显偏向对E3a不利，这时E3a的结论要结合"E3a对基座、不预热"的描述性比较一起解读。这一点请在预注册里写明。

2. N = 0的点：选(b)，跑。

这一项我和建议不同。H5的说法是"内化后的模型学得更快"，而没有N = 0这个点，就分不清两件事：

截距： E3b一开始就更高，比如它本来就更会输出mask；
斜率： E3b学想象任务学得更快。

如果E3b在1K上的优势等于它在N = 0上的优势，那只是起点领先，算不上学得更快。代价约3小时评测，加一个"只评起点"的小入口，值得。

具体做法：基座加预热与E3b在N = 0上的读数，在预注册里写明它们用于区分截距与斜率，不单独参与H5判定。RUN-0032的零样本照旧只作参照，因为它的数字网格格式全部无效，给不出这个起点。

3. 图像到文本的迁移：选(c)，在(a)的基础上加E3a。

e类（只给文字、要求构建意象）是整个项目里最接近"LLM能力跃迁"的那一项检验。E3a和E3b在这里的对比，也正好检验G2时写下的机制预测：E3b把视觉信息带到了输出端，迁移应当更大。多2.5小时，排期上有余量。

4. H5的判定档：选(a)。 1K、4K两档各自判定：两档都满足，记"H5成立"；只有一档满足，记"部分支持"。16K和64K只描述差距是否随数据量缩小。另外，请事先写好"部分支持"在论文里怎么表述，免得到时临场措辞。

5. 顺序：同意。 N = 0的读数很便宜，可以排在最前面跑，它也能顺带检验评测入口是否正确。

三、关于VISTA（Han等，arXiv 2610.02200）

定位： VISTA和我们是同一个诊断的两面。它在模型外部，用无损视觉记忆和模型自主的回看与放大来重读像素；我们在模型内部，让信息留到输出端并能表达出来，进而支持想象。论文的相关工作里引用它，并写明这一区别。

现在可以做的（不影响10月25日的排期）：

E3b的多轮模式借鉴VISTA的三个设计：
保留每一轮的叠加图，而不只是最新一轮；
由模型自主选择放大区域，和边界细化合并成同一个机制；
提供精确的网格读数。
这三点都按硬约束第11条，作为固定的、与任务无关的流程记计算量。是否在检查点前实现，按工作量判断。
可选小实验： 给Qwen-9B配一个"放大"工具，跑E5的零样本。预测（运行前写进预注册）：先决条件的mask IoU可能改善，起伏判定不会改善，也就是工具帮模型看清，不帮它想象。

检查点之后：

2×2实验： 模型（基座，对比E3内化）× harness（最小，对比VISTA式回看与放大），先在静态任务上测（BabyVision视觉追踪类和E5）。看内化是减少了模型从"再看一遍"里得到的增益，还是与harness的增益相加。
心智的行为指标： 把E5生成器做成可交互环境，放进VISTA式harness，比较基座与内化模型完成任务所需的行动数，3D场景优先。依据是VISTA在3D渲染下，动作数从7,302升到20,640，分数降到84.12，这正是内在模拟应当发挥作用的地方。
