## 〇、方向调整

这一轮的投稿决定暂缓，改由第三节的去留规则决定。

新增一条主线，叫 **W1（仪器工作台）**：

- LLM 保持冻结，不改权重；
- 只给它不含学习的通用工具，让它完成高层 CV 任务；
- 心智仍然是长期目标，但这一轮 CVPR 不以它为主线。

论文按三段式组织：

1. **诊断（E1、E2）**：LLM 知道东西在哪，画不出轮廓，而轮廓信息就在它的中间层。
2. **内化路线（E3 加 9B）**：训练能教会 LLM 画，但会和语言争抢，这种干扰随规模缩小。
3. **工具路线（W1）**：不改权重，只给通用工具，同一个 LLM 就能把轮廓画出来，语言能力不受影响。

E5 作为诚实的否定结果写进论文，放补充材料或正文的一小节。

## 二、W1：任务书

### 1. 主张

冻结的 LLM，配上只含仪器的工作台，在高层 CV 任务上明显超过它自己的零样本表现，尤其是分割；语言能力按构造不受影响；"换模型、换工具"的消融证明，能力属于 LLM，而不是工具。

### 2. 工具的边界（W1 的硬约束）

原则是：**语义判断由 LLM 做，底层拟合交给不含学习的算法。**

**允许：**

| 角色 | 工具 |
|---|---|
| 眼 | 裁剪、放大、像素与颜色读数、分块查看 |
| 手 | 框、点、多边形、样条；光栅化；叠加渲染 |
| 贴边 | 边缘检测、GrabCut、分水岭、超像素（SLIC）、引导滤波、形态学运算、连通域；参数固定的 CRF |
| 核对 | 把结果叠加回原图，交给模型再看一次 |
| 编排 | Python 沙箱，只允许 numpy、scipy、OpenCV 和 scikit-image 中不含学习的函数，不联网 |

**禁止：**

- 任何学习型视觉模型或预训练权重，包括 SAM、检测器、深度模型、CLIP、DINO、OCR 模型；
- OpenCV 的 DNN 模块。

**工作台必须与任务无关**：所有任务用同一套工具、同一个回路。按任务写的提示词，只说明任务是什么、输出成什么格式，不写解题方法。

### 3. 模型

- **主力**：Qwen3.5-4B、9B，外加 2B，用来看能力随尺寸的斜率。
- **27B**：列为可选。它要两张卡做张量并行，只在主体实验做完、两张卡都空闲时再跑。
- 全部用后训练版本的原始权重。

### 4. 回路协议（在开发集上定，跑 test 之前冻结）

- **每条样本的上限**：
  - 最多 6 轮，最多 8 次工具调用；
  - 每轮思考最多 2048 个 token，到上限就强制收尾，与 E5 的口径一致。
- **最终答案的格式**：与 E1 的 T 通道一致。框用原生格式；mask 由工具光栅化后提交；计数直接给数字。
- **出错时**：发现结果不对，回到原图重画，而不是在错的结果上修补。
- **计算量**：每条样本记录 token 数、工具调用次数和墙钟时间，按硬约束第 11 条记账。

### 5. 任务与数据

- **RefCOCO 系列的指代分割**：主任务，报 cIoU、gIoU。
- **RefCOCO 系列的定位**：报 Acc@0.5。
- **CountBench**：报准确率。
- **检测子集**：可选。
- **数据划分**：
  - 从 RefCOCO 的 val 里，取 300 句作**开发-调参集**，只用于调提示词和工具；
  - 再取不重叠的 500 句作**开发-检查集**，只用于第三节的去留判定；
  - 主结果用 testA、testB 等 test 划分，每个划分取 1,000 句的固定子集。
- 去重规则照旧。

### 6. 对照与消融

| 编号 | 设置 | 说明什么 |
|---|---|---|
| W1-0 | E1 零样本（不给工具），同一模型 | 起点 |
| W1-1 | 完整工作台 | 主结果 |
| W1-F | 固定流程：E1 里模型自己的框，直接交给 GrabCut，没有 LLM 给的点、修正和核对 | 只靠工具能拿到多少（换工具的一侧） |
| W1-S | 同一个工作台，换 2B、4B、9B | 能力是否随 LLM 变强（换模型的一侧） |
| W1-A1 / A2 / A3 | 分别去掉眼、核对回路、贴边 | 各类工具各自的贡献 |
| 参照 | E3b（2B，训练过的）、LISA-7B、专家 SOTA（灰色参考线） | 定位在哪条赛道 |

语言能力：W1 按构造不变，因为权重完全没动。仍然报告健康检查，并注明与基座逐位相同。
