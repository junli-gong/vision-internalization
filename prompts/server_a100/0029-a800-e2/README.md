这次是 E2 的正式实验：在冻结的 Qwen3.5（0.8B、2B、4B、9B）的各层隐藏状态上训练小探针，看深度、语义分割、法向、指代分割的信息在哪些层里。

- **沿用 RUN-0022 的工作目录**，例如 `/root/autodl-tmp/visint-0022`：venv、权重、`data/`（含去重剔除清单）都不动，只换代码快照。
- **用时**：约一天，GPU 约 25–30 小时，主要在第 3 步。第 2 步会先重测用量，超过批准的上限就自动停下。
- **不需要改任何代码。** 遇到报错不要自己修，原样记下来，写进 notes.txt。

## 0. 包里有什么

| 文件 | 作用 |
|---|---|
| `vision-internalization-<commit>.tar.gz` | 代码快照，完整 commit 见 `VERSION.txt` |
| `common.sh` | 各步共用的环境设置，不单独运行 |
| `step1_update.sh` | 第 1 步：换代码，在 GPU 上跑上采样的单元测试（约 5 分钟） |
| `step2_estimate.sh` | 第 2 步：重测四个模型的用量，判定 GO 或 STOP（约 20 分钟） |
| `step3_run.sh` | 第 3 步：预跑、收敛判定、正式运行、噪声底（约一天） |
| `step4_collect.sh` | 第 4 步：打包结果，不含检查点 |

## 1. 准备

- **磁盘**：探针检查点写在 `<工作目录>/e2_ckpt_0029*`，约 10–20 GB；结果约 1 GB。上次剩约 150 GB，够用。
- **网络**：不需要，全程离线。
- **显存**：9B 约 25 GB，A800 80 GB 足够。

## 2. 步骤

```bash
W=/root/autodl-tmp/visint-0022
bash step1_update.sh $W
bash step2_estimate.sh $W          # 最后一行写 GO 或 STOP
# 只有第 2 步写 GO 才运行第 3 步；放进 tmux 或 nohup：
bash step3_run.sh $W               # 中断了重新运行同一条命令，会从检查点接着跑
bash step4_collect.sh $W           # 随时可以运行，先回传已完成的部分
```

- 每一步的退出码都记在 `<工作目录>/results_0029/steps.log`。
- 当前进度写在 `results_0029/progress.txt`。

## 3. 第 3 步会自己停下的三种情况（都属正常，照实回传即可）

1. **预跑没有收敛**：退出码 3，`prerun_check.json` 里写明是哪一层没过。
2. **累计用时超过上限的 120%**：退出码 4，在当前模型跑完之后停。
3. **某个任务出错**：记进 `steps.log`，继续下一个模型。
