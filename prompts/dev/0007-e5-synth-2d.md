## 任务

### 1. 公共框架（`src/synth/`）

- **场景规格**：用 dataclass 描述，可序列化成 JSON。包含：
  - 物体列表：身份、形状参数、颜色或纹理、位姿、z 序；
  - 背景；
  - 相机或画布（默认 512×512 RGB）。
- **物体身份与划分**：
  - 物体身份 = (形状族, 离散化的形状参数, 颜色或纹理 id)。
  - 形状族至少包括：圆、椭圆、矩形、三角形、正多边形（5–8 边）、星形、十字、L 形、月牙。
  - 身份空间用固定规则预先切成 train/val/test 三个互不相交的集合，默认比例 80/10/10；规则写进 docstring。
  - 场景种子空间同样按划分互不相交。
  - 形状族在各划分之间共享（划分发生在实例层面）。另提供一个可选的"留出形状族"模式：整族只出现在 test，给以后更难的泛化测试用，默认关闭。
- **难度分档**：每类任务有自己的连续难度量，按固定档位分箱。样本元数据里写明连续值与所在档位。
  - 生成时可以指定档位，按档位均衡采样。
- **目标**：
  - 全分辨率二值 mask（bool）；
  - 用 `grid.codec.mask_to_grid` 得到的 N×N 网格，N 默认 32，可配置；
  - 需要时每个物体一张 mask。
- **指令文本**：英文，按任务有一小组固定模板，样本元数据记模板 id。模板集合在各划分之间相同。
- **数据集接口**：
  - `generate(task, split, index, **cfg) -> Sample`，Sample 含图像（没有图像的任务为 None）、指令、目标、元数据、平凡基线的预测；
  - 可迭代的数据集类；
  - 可选的导出功能：PNG、npz、JSONL 清单。

### 2. c 遮挡补全

- **场景**：若干 2D 物体按 z 序叠画。目标物体被一个或多个遮挡物部分遮住。
- **输入**：图像，加上指明目标物体的指令（用颜色与形状描述，保证在场景里唯一）。
- **目标**：目标物体的完整（非模态）mask。
- **难度**：目标被遮住的面积比例，分三档：[0.1, 0.3)、[0.3, 0.5)、[0.5, 0.7)。
  - 被遮住的部分必须不能由可见部分平凡推出：至少要求"可见部分的凸包"与真值的 IoU 低于某个阈值的样本占一定比例。
  - 阈值与比例由你定，写进偏离，并报告三个档位上两种平凡基线的 IoU 分布。
- **平凡基线**：可见部分的 mask；可见部分的凸包。

### 3. d 短时物理（pymunk，侧视）

- **场景**：地面加若干刚体（盒子、圆）。动作三种：
  - 放下（从高处释放）；
  - 推（给定冲量）；
  - 碰撞（两个物体相向运动）。
- **输入**：初始帧图像 + 动作文字 + 步数 k。
- **目标**：k 步之后各物体的 mask。
  - 按物体给出二值 mask，由指令点名要哪个物体；
  - 另存全部物体的 mask。
- **时间与分档**：
  - "一步"的物理时长固定，建议 1/30 秒，内部可以再细分子步。写进常量与文档。
  - k 分档，建议 {5, 10, 20, 40}。
- **平凡基线**：
  - 原样复制初始 mask；
  - 匀速外推：用动作给定的初速度（放下时初速为 0，所以等于复制；推和碰撞按给定速度平移）。
- **物理合理性检查**：
  - 静止物体保持静止；
  - 放下的物体最终落在地面或其他物体上；
  - 没有明显的相互穿透（给出容差）。
  - pymunk 的确定性：同一种子两次模拟结果逐位相同，写测试。

### 4. e 文本到意象

- **输入**：只有文字，没有图像。文字描述一个 2D 场景（物体、位置、大小，用归一化坐标或网格坐标，由你定并说明），加一个变换（平移、旋转、缩放，或它们的组合）。
- **目标**：变换之后的布局网格，即目标物体的二值网格。
- **难度**：变换幅度分档，例如平移距离、旋转角、缩放因子。
- **平凡基线**：按文字直接放置、不做变换。
- 场景来自与 c/d 相同的场景规格与身份划分，保证文字里的物体在划分之间同样不重叠。

### 5. 测试（`tests/test_synth*.py`）

- **可复现**：同一 (任务, 划分, 序号) 两次生成逐字节相同；不同序号不同。
- **划分**：各划分的物体身份与场景种子两两不相交，用大样本检查。
- **难度**：按档位生成的样本，其连续难度值确实落在档内。
- **目标与图像对齐**：mask 像素处的图像颜色等于该物体的颜色，给出容差或抗锯齿处理。
- **平凡基线**：在构造的小例子上结果正确。
- **物理**：见上面的合理性检查。
- **速度**：c 与 e 在单核上 ≥ 50 样本/秒，d 另报实测速度。
