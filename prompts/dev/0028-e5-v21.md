## 任务

### 1. 凸起先验基线（`src/synth/relief.py` 及 a、b 两类的基线）

- **定义**：
  - 对一个 mask（网格级），每个前景格的起伏档 = 平均档减去 `A × f(d)`，其中 d 是该格到 mask 边界的距离（格单位，例如到最近背景格的欧氏或切比雪夫距离），f 是单调的归一化函数。离边界越远，越近相机，档号越小。
  - 只有一个幅度参数 A（档数）。
  - 精确定义（距离类型、归一化、取整）写清楚；全程整数或 decimal，满足 D24 的确定性要求。
- **基线**：
  - a 类：`copy_convex`，mask 用原样复制，起伏用凸起先验。
  - b 类：同样做 `copy_convex`。
- **选 A**：在 val 划分上用网格搜索（例如 0–8 档），以 30° 以上三档的平均起伏误差最小为准，选定后写进配置冻结。不在 test 上选。
  - 项目负责人在 v4 上选的是 4 档。我们选出的值不同的话照实写，不向他的值靠。
  - 用选定的 A 在 test 上复算他那张表（每档 80 条），并排对照。

### 2. b 类：起伏网格与真值仿射（`src/synth/viewpoint.py`）

- b 类输出与 a 类同样的 33 符号起伏网格：背景 + 32 档，取相对物体平均深度、按外接半径量化，定义与 a 相同。
- 起伏误差、真值拟合的二维仿射基线（含起伏）、平面、凸起先验，都在 b 上实现，口径与 a 相同。
- b 的任务版本加一，重新钉住 b 的摘要。a、c、d、e 的摘要不许变，a 只新增基线字段：新增字段不进摘要的话，a 不改版本；进的话也加一。写明是哪种。

### 3. 门槛函数（`src/e5/scoring.py`）

- **判定条件**：在 30° 以上三档，起伏误差同时低于平面、真值仿射、凸起先验三条基线。
  - 每一条用逐样本配对的 bootstrap 95% CI，上界 < 0 才算胜过；
  - 三条都胜过才判"想象"成立。
- **先决条件**：网格 mask IoU 胜过最强的非真值基线，同样用配对 CI 判。
- **报告**：每条基线各自的差值、CI、中位数；照字面的旧判法不再作为判定，只在 README 里注明已作废。
- 适用于 a 类与 b 类的环绕。

### 4. 思维链（`configs/e5_prompts.json`、`src/e5/`）

- **a、b 两类**：先文字推理，最后输出 33 符号起伏网格，复用零样本 a 的符号表说明。c、d、e 仍输出多边形 JSON。

  adapter.generate_batch_budgeted(inputs_list, *, thinking_budget: int, answer_budget: int,

  - 本任务的测试用一个实现了这个签名的假适配器。DEV-0027 合入后，管理员会合并验证真实路径。
  - 配置：`thinking_budget = 4096`、`answer_budget = 1024`。解析只看 `answer_text`。
  - metrics 按自然收尾与强制收尾分开报，并给条数。
