## 任务

### 1. `src/e2/` 与 `scripts/run_e2.py`

- **输入口径**：图像口径沿用 E1 冻结的（D28-3，`image_policy`）。
  - 深度、分割、法向用"图在前"，提示固定为一句与任务无关的话，写进配置。理由：图像 token 看不到后面的文字（因果注意力），层表征与任务无关。
  - 指代分割用"指令在前"，把指代句放在图像之前。
- **特征**：一次前向取全部选定层在图像 token 位置的隐藏状态（`hidden_states`，冻结、no_grad、bf16），排成 token 网格 [H_t, W_t, D]，网格形状由适配器的图像 token 信息给出。
  - **在线**：不落盘缓存特征。9B 每张图约 256 MB，简报 §5.3。
  - 同一批特征同时喂给所有层的探针：每层一个探针、一个优化器。
- **探针**：
  - 线性：1×1 卷积，D → C；
  - 两层卷积：3×3、D → 256、GELU、3×3、→ C。
  - 输出在 token 网格分辨率，**双线性上采样**到 GT 分辨率后算损失与指标。
  - 每层特征先做固定的归一化，例如按通道的运行均值与方差，写明。
- **任务、损失与指标**：

  | 任务 | 数据（训练 / 评测） | 损失 | 指标 |
  |---|---|---|---|
  | 深度 | NYU BTS 训练集 / NYU 官方 654 | log 深度上的 scale-invariant L1 或 SILog（写明） | AbsRel、δ1、RMSE，Eigen crop（D11-2） |
  | 语义分割 | ADE20K train / val 2,000 | 交叉熵，忽略 0 | mIoU（150 类）、像素准确率 |
  | 法向 | NYU labeled 795 / 654 | 余弦损失，带有效掩码 | 平均角度误差、中位角度误差、11.25°/22.5°/30° 内的比例 |
  | 指代分割 | RefCOCO 训练图与 refs / RefCOCO val | 二值交叉熵 + Dice | cIoU、gIoU |

  - 指标尽量复用 `src/metrics/`，缺的补上并测试。
  - 评测在全部评测集上做，不抽样，带 bootstrap CI。
- **层**：`--layers all` 或 `--layers every 2`，按 `num_layers()` 展开，写进配置。另有参考线：
  - `--reference post_proj`：即第 0 层，会提示它与第 0 层相同；
  - `--reference pre_proj`：视觉塔在投影或合并之前的输出。现有适配器没有这个接口的话，写在总结里，不要改适配器。探针头要能处理不同的维度。
- **训练**：
  - 固定种子、固定步数、固定学习率与调度（全部写进配置，同一份用于所有模型与层）；
  - 每隔 N 步在一个固定的小验证子集上记一次曲线，最后在评测集上评一次；
  - 不按评测集挑步数或超参。
- **输出与续跑**：
  - 输出：`experiments/E2/<编号>/<模型>/<任务>/`，含逐层的 metrics、曲线、config、README（逐层曲线表）；
  - 支持断点续传：保存探针的状态与优化器；
  - 记账：GPU 墙钟、前向次数、显存峰值。
- **吞吐与算力估算**：`--estimate`，按每个模型与任务的步数外推 GPU 小时，用于 E2 预注册。

### 2. 测试

- 小型随机模型，`--tiny`，CPU：三个家族、四个任务、两种探针都跑通，续跑逐字节一致。
- 网格排布：token 序列 ↔ [H_t, W_t] 的映射与适配器的图像 token 信息一致。Qwen 的 merge 后网格、InternVL 的单 tile、Gemma 的 soft token 网格都要覆盖。
- 指标在构造例子上与手算一致。
- "指令在前"时，图像 token 的隐藏状态随指令改变；"图在前"时不随文字改变。复用冒烟里的任务调制检查思路。
