## 任务

### 1. 3D 场景与渲染（`src/synth/` 新模块）

- **实体**：程序化网格，低面数，顶点量化。至少包括长方体、球（二十面体细分）、圆柱、圆锥、圆环、三棱柱或六棱柱、拉伸的 L 形。
  - 身份 = (实体族, 离散化的比例参数, 外观)，划分规则同第一部分：实例层面，可选留出整族。
- **相机**：针孔相机，固定内参。外参由场景规格给出，全部量化。
- **光栅化**：
  - 三角形覆盖用像素中心加整数边函数，与 `raster.py` 同一边界规则；
  - 深度取精确或量化后的插值，z-buffer 决定可见性，等深时用确定的规则打破平局；
  - 同一个光栅化器同时给出三样东西：物体 ID 图、深度图、Lambert 着色的 RGB（固定的平行光，量化法向）。图像、mask 与深度按构造对齐。
- **深度**：场景尺度要让深度落在 `src.constants` 的 `D_MIN`–`D_MAX`（0.5–10 m）之内，写成元数据与可选的深度网格。

### 2. a：出平面三维旋转

- **输入**：物体（或小场景）的图像 + 文字给出的旋转（轴与角度）。
- **目标**：旋转后该物体的 mask 网格；可选深度网格。
- **排除平面内旋转**：
  - 旋转轴只取与视线垂直的方向，即相机坐标系里的水平轴或竖直轴；
  - 或者要求轴与视线的夹角 ≥ 60°。
  
  二选一，写明。
- **对称实体的旋转等价**：结果与某个更小的等价旋转相同时，改为报告等价角，做法同 e。
- **难度**：角度分档，例如 [15°, 30°)、[30°, 60°)、[60°, 90°)、[90°, 180°]。
- **平凡基线**：
  - 原样复制当前 mask；
  - **由指令推得的二维仿射**：用正交近似把 3D 旋转作用在物体投影的质心与二阶矩上，得到一个 2D 仿射，再作用到当前 mask 上。它不看真值，是判"在想象"的门槛。
  - 另报一个**真值拟合的最佳二维仿射**：用矩匹配从真值拟合，作为"任何 2D 方法的上界"参考线，不参与判定。

### 3. b：视角变化

- **输入**：多物体场景的图像 + 文字给出的相机移动（绕场景中心水平环绕 θ 度，或平移），场景里的物体用颜色与形状点名。
- **目标**：新视角下点名物体的 mask 网格；另存全部物体的 ID 图。
- **难度**：环绕角或平移量分档。
- **平凡基线**：
  - 原样复制；
  - **二维平移**：按场景质心投影的位移平移 mask。

### 4. 通用

- 指令模板与第一部分一致：英文、固定小模板集、不含输出格式说明。
- 所有数都是生成真值时用的精确值。写一条测试：只从指令文字反解出变换，再渲染，结果与目标逐位相同。
- 纳入 `generate` 与数据集类。
- 钉住摘要：
  - `tests/data/synth_digests_v2.json` 里 a、b 各 60 个，按 c/e 的规则，任何平台必须相同；
  - `scripts/synth_pin_digests.py` 支持新任务；
  - 如果文件结构要升级，写进偏离。
- **速度**：单核 ≥ 20 样本/秒。报告实测值。

### 5. 测试（`tests/test_synth_3d*.py`）

- **可复现**：逐字节重现；与全局随机状态无关；换 hash seed 的新进程结果相同。
- **桩测试**：把平台超越函数与 np.mean 换成抛异常的桩，a、b 仍能生成且摘要不变。
- **光栅化**：
  - 与独立的纯 Python 精确参考（Fraction）逐位相同；
  - 共用边的三角形不重不漏；
  - 立方体正视时像素数与解析值相同。
- **深度**：在构造例子上等于解析值；落在量程内。
- **排除平面内旋转**：测试所有样本的旋转轴都满足约束。
- **平凡基线**：在构造例子上结果正确；报告各档两种非真值基线与真值仿射上界的 IoU 分布（均值与分位数）。
- **划分**：各划分的身份与场景种子两两不相交。
