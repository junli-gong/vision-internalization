## 3. 落地

```bash
python scripts/data/land_e1.py all --root $PROJ/data --tmpdir /dev/shm/visint/tmp \
  --nyu-local-dir /home/ubuntu/workspace/wzg/gjl/datasets/nyuv2
```

- **`--nyu-local-dir`**：
  - 那是别的项目的目录，**只读**，不复制、不修改；
  - 脚本会流式核对官方文件的 sha256（约 3 GB 网络），一致才用本地文件，不一致就下载到 TMPDIR。
  - 如果该目录里没有 labeled `.mat`，就不加这个参数重跑 nyuv2。
- **退出码**：
  - 2：有不可达的 URL。照常推回清单，report 里列出，再对失败的源单独重跑一次。
  - 3 或 4：预算或磁盘红线。**停下报告**。
- **记账**：每个源落地前后各记一次 `df /`、`du -sh $PROJ/data` 与内存盘占用。
  - 本项目根盘合计（`$PROJ` 整体）不得超过 15 GB；
  - 预计数据约 3.1 GB。

## 4. 配置文件

产物都写进 `experiments/P0/0010_e1_data/`：

1. `python scripts/data/build_e1_configs.py dev-subsets --root $PROJ/data --check`
   - 与入库的 `configs/e1_dev_subsets.json` 逐项一致才算通过；
   - 不一致就用 `--out experiments/P0/0010_e1_data/e1_dev_subsets.json` 写出新版，并在 report 里列出差异。
2. `python scripts/data/build_e1_configs.py nyu-pairs --root $PROJ/data --out experiments/P0/0010_e1_data/e1_nyu_pairs.json`
3. 用上一步的点对，生成评测子集：

   ```bash
   python scripts/data/build_e1_configs.py eval-subsets --root $PROJ/data \
     --pairs-config experiments/P0/0010_e1_data/e1_nyu_pairs.json \
     --out experiments/P0/0010_e1_data/e1_eval_subsets.json
   ```

4. 用加载器把每个评测集的 n 读一遍（`subset=eval` 与 `subset=dev`），并读出点对的剔除统计（`n_valid_pixels_total`、`n_candidate_pixels_total`、缺口），写进 `counts.json`。
